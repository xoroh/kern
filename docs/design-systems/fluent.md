**Identity:** multi-platform system (Web / iOS / Android / Windows component sets), editorial craft, Figma-plugin-grade design tooling, Teams/Outlook proof.
**Sources:** SITE-REDESIGN-benchmark.md (Fluent home); fluent2.microsoft.design.

## Parts: they-have / we-will-have
- Web (Fluent UI React: button, dialog, menu, dropdown, tabs, table, tooltip, avatar, badge, card…): Y / **B** for M3-overlapping.
- Native platform sets (iOS/Android/Windows): Y / **N** (kern-native is the counterpart; kern's edge = one contract across web+native, Fluent keeps per-platform sets).
- Platform-split IA (components organized by platform): Y / steal the split for kern's web/native presentation.
- Design tooling (Figma plugins: a11y focus-order, contrast checker, content reel, icon scaling): Y / kern Figma kit should include the a11y plugins as a checklist item.
- Tokens (web: `teams` themes; shared color ramps): Y / kern-theme (M3 roles).

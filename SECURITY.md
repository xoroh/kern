# Security Policy

## Supported versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

`0.x` is pre-stable; upgrade to the latest patch within `0.1.x`.

## Reporting a vulnerability

Report privately via **GitHub Security Advisories**
(Security tab → Report a vulnerability) on the affected repo. Include:

- Affected package and version (`@xoroh/kern`, `@xoroh/kern-emdash`, `@xoroh/kern-mcp`)
- Steps to reproduce and impact assessment

Expect acknowledgment within 72 hours. Do not open public issues for
unpatched vulnerabilities.
